# 🏢 외주구매팀 스마트 업무관리표 (Procurement Scheduler)

> **외주구매팀 전용 스마트 스케줄러 & 연쇄 업무 파이프라인 관리 플랫폼**  
> 팀원들의 업무, 미팅, 입찰, 서류 제출부터 주말/공휴일/연차/지정연차가 자동 반영된 **정밀 영업일(Business Day)** 기준 D-Day 계산 및 **연쇄 업무 파이프라인**을 제공합니다.

---

## 🌟 핵심 기능 (Key Features)

### 1. 🔗 연쇄 업무(Chain Process) 파이프라인
- **4열 가로 스크롤 레이아웃**: 한 화면에 최대 4개의 연쇄 업무 카드가 깔끔하게 나열되며, 초과 시 터치/마우스휠 가로 스크롤 지원.
- **체인 순서 및 위치 변경**: 2D 모달에서 `▲(위로)` / `▼(아래로)` 버튼으로 순서를 손쉽게 조정하고, 개별 항목 제거(`X`) 및 신규 일정 연결 가능.
- **영업일 3일 보존 자동 해제 규칙**: 연쇄 업무의 마지막 마감일이 지난 후 **영업일 기준 3일간 보존**되며, 4영업일째 되는 날 개별 일정 데이터는 유지한 채 **선후 연결 이력만 자동 해제**되어 깔끔함 유지.

### 2. 🗓️ 정밀 영업일(Business Day) 계산 엔진
- **자동 차감 대상**:
  - 주말 (토요일, 일요일)
  - `HOLIDAY` (공휴일)
  - `COMPANY_HOLIDAY` (지정연차)
  - `PERSONAL_LEAVE` (연차/휴가)
- 실무자의 실제 출근일(영업일)만을 집계하여 **지연 영업일수** 및 **D-Day**를 정밀하게 추적합니다.

### 3. 📊 5가지 다중 업무 관리 뷰
- **대시보드 (Dashboard)**:
  - **전체 일정 타임라인**: 과거 일정을 보존한 상태에서 진입 시 **오늘 일자/예정 일정 위치로 자동 스크롤 포커싱**되어 바로 확인 가능.
  - **오늘의 할 일 vs 다가오는 마감일 분리**: 당일 일정은 '오늘의 할 일'에 집중 노출하고, '다가오는 마감일'은 **내일부터의 마감 예정 일정**만 명확히 필터링 조회.
- **풀 캘린더 (Calendar)**: 월별/일별 시각적 스케줄링 및 퀵 일정 추가.
- **영업일 현황판**: 지연 경고 업무 및 팀원 연차 현황 실시간 파악.
- **주기별 업무 관리**: 연/반기/분기/월/주 단위 정기 점검 항목 및 완료 시 차기 일정 자동 생성.
- **메모 보드**: 포스트잇 스타일 메모 및 고정(Pinning) 기능.

### 7. 📱 모바일/갤럭시 폴드7 커버스크린 전용 UI & 뷰 전환 (Mobile UX & View Switcher)
- **모바일/데스크톱 뷰 자유 전환**: 상단 헤더의 `[💻 PC 뷰로 변경]` 버튼 및 PC 사이드바 하단의 `[🌙 다크모드]` / `[📱 모바일 뷰]` 나란히 배치 버튼으로 화면 모드를 직관적으로 상호 전환 가능.
- **갤럭시 폴드7 세로 화면 최적화**: 커버 스크린과 같이 세로로 길고 좁은 스마트폰 화면에서도 시인성이 뛰어난 하단 탭 바(캘린더/작업현황/[+플로팅 퀵추가]/대시보드/메모장) 제공.
- **반응형 1컬럼 터치 레이아웃**: 복잡한 다중 컬럼 레이아웃을 모바일 전용 1컬럼 스택 구조로 자동 전환하여 작은 화면에서도 가독성과 조작 편의성을 극대화.

## 🚀 개발 및 실행 방법 (Getting Started)

### 사전 요구사항
- [Node.js](https://nodejs.org/) v18 이상

### 로컬 실행
```bash
# 1. 의존성 패키지 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 브라우저에서 접속
http://localhost:3000
```

### 프로덕션 빌드
```bash
npm run build
npm run start
```

- **FIX (동기화 중 탭 전환/독립 작업 안정성)**: 백그라운드 데이터 동기화 도중 대시보드/작업현황 탭 이동 시 발생하던 `Null/Undefined` 참조 및 루프 바인딩 예외를 차단하는 100% 방어 가드(Sanitizer Null Guard, Loop Max Limit)를 구축하여 자유로운 멀티태스킹 보장
- **FEAT (실시간 프로그레스 바 & 퍼센트 UI)**: 텍스트 형태의 경과 시간 표시 대신 좌에서 우로 채워지는 동적 프로그레스 바 및 실시간 퍼센트(`0%` ~ `100%`) 표시 토스트 팝업 적용
- **FEAT (동기화 상태 직관적 안내 & 15초 타임아웃 방어)**: 낙관적 UI 적용으로 화면 저장은 0.01초 만에 즉시 반영되고 구글 시트 웹훅 기록이 백그라운드에서 진행됨을 명시하는 직관적 안내 문구(`✓ 화면 반영 완료 (구글 시트 백그라운드 저장중)`) 탑재 및 15초 응답 초과 시 무한 로딩 방지 타임아웃 트랩 적용
- **FEAT (동기화 실패 원인 상세 표기 토스트 UI)**: 화면 우측 하단 동기화 실패 발생 시 단순 오류 문구 대신 실제 예외 원인(GAS_WEBHOOK_URL 환경변수 미설정, HTTP 500 오류, 웹훅 서버 응답 실패, 네트워크 disconnect 등)을 상세 메시지 박스로 표기하고 닫기(`[X]`) 버튼 제공
- **FIX (GAS Webhook 302 리다이렉트 keepalive 예외 수정)**: 구글 시트로 데이터 저장은 정상 완료되지만 Google Apps Script(GAS)의 `302 Found` 리다이렉트 수신 시 Node.js fetch의 `keepalive: true` 도메인 이동 예외(`TypeError: fetch failed`)로 인해 우측 하단 팝업이 '동기화 실패'로 거깃 표기되던 핵심 버그를 완벽히 해결 및 방어 처리
- **FEAT (0.01초 초고속 SWR 부팅)**: 초기 접속 시 구글 시트 응답(20초)을 멈춘 채 기다리지 않고 `localStorage` 데이터를 0.01초 만에 즉시 화면에 띄운 후 백그라운드에서 최신 데이터를 동기화하도록 대폭 최적화
- **FIX (GAS DB 동기화 모드 고정)**: 초기 로딩 시 구글 시트 응답 지연/초기화 과정에서 DB 모드가 '로컬 모드'로 잘못 덮어씌워지던 이슈를 수정하여 구글 시트 동기화 모드(`dbStatus="GAS"`)를 안전하게 고정
- **FEAT (정기 업무 모달 기간 범위 표기)**: 정기 업무 상세 모달 내 개별 회차 날짜 표시를 단순 마감일에서 시작일자~종료일자 범위(`2026년 08월 10일 (월) ~ 08월 13일 (목)`)로 표기하도록 보완
- **FEAT (지난 정기 업무 접기/펼치기)**: 오늘 이전 지나간 과거 반복 회차 일정을 `[지난 일정 N개 보기 (펼치기)]` 아코디언 토글 섹션 아래로 자동 숨김 처리하여 목록 시인성 확보
- **FEAT (예정(대기) 뱃지 정리)**: 불필요한 '예정(대기)' 뱃지 태그를 삭제하고 '완료' 및 '진행중' 상태만 깔끔하게 시각화
- **FIX (주기별 업무 갑지 예정 시점 보존 및 대표 패턴 추출 엔진)**: 개별 회차 수정(`isSingleEdited`) 시 개별 일자의 시작/종료일이 변경되어도 주기별 업무 관리 메인 테이블(갑지)의 예정 시점(예: `매월 11일~13일`)이 왜곡되지 않고 최초 등록 및 `[전체 일괄 수정]` 시 적용된 그룹 대표 일정 규칙을 엄격히 유지하도록 제어 엔진 탑재
